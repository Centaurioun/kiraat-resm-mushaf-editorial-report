# Source Files

## Canonical current manuscript

`manuscript/current/redaktorden_gelen.docx` is the canonical current manuscript for the staged editorial workflow.

A second file available in the ChatGPT workspace had the name `redaktorden_gelen(3).docx`; its SHA-256 hash was identical to the canonical current file, so the duplicate copy is intentionally not included in this bootstrap package.

`manuscript/current/redaktorden_gelen_extracted.md` is a searchable text extraction used to make GitHub/Codex inspection easier. When formatting, footnotes, Arabic layout, or other Word-specific features matter, the DOCX remains authoritative.

## Archive

`manuscript/archive/` contains an earlier manuscript version for historical comparison only. Never prefer it over the current manuscript.

## Reports

`reports/` contains the three earlier reports plus the combined report. They are evidence/input for the fourth-report workflow, not the final author-facing deliverable.

## Notes

`notes/duzeltilecekler.docx` contains the redactor/author correction checklist and must be considered when building the issue inventory.
